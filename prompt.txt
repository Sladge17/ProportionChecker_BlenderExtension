1. Цель проекта:
    - созданме аддона для blender

2. Описание аддона:
    - должна поддерживаться работа в blender начиная с версии 5.0
    - должен быть реализован пользовательский интерфейс

3. Требования к аддону:
    - на вход поступает путь до целевой директории
    - в целевой директории производится поиск растровых изображений
    - на основании информации о растровых изображениях в blender сцене выстраивается сетка из плоскостей
    - сетка из плоскостей центрируется относительно глобальной системы координат blender
    - количество столбцов в сетке равно количеству строк
    - пример формирования сетки:
        - 4 изображения = 2 столбца, 2 строки
        - 5 изображений = 3 столбца, 2 строки
        - 7 изображений = 3 столбца, 3 строки
        - 9 изображений = 3 столбца, 3 строки
    - плоскости заполняют сетку последовательно, построчно
    - одна плоскось ассоциируется с одним изображением
    - размеры плоскости пропорциональны размеру изображения с которым она ассоциируется
    - есть возможность задавать расстояние между плоскостями, отдельно по вертикали и горизонтали, по умолчанию задан ноль
    - высота плоскости 1 метр, по умолчанию
    - для каждой плоскости создаётся отдельный материал, где в поле Base Color назначается ассоциируемое с плоскостью изображение
    - плоскости хранятся в отдельной коллекции "Reference"
    - коллекция "Reference" невыделяемая
    - режим сцены в blender: solid с отрисовкой текстур
    - видовая камера смотрит на сетку плоскостей перпендикулярно, сетка занимает максимально возможное место

4. Требования к интерфейсу:
    - удовлетворение условиям: bl_space_type = 'VIEW_3D', bl_region_type = 'UI'
    - поле ввода целевой директории
    - выбор плоскости на которой будет построена сетка плоскостей
    - две строки с двумя столбцами для числовых значений
        - первая строка, первый столбец: опорный размер на изображении
        - первая строка, второй столбец: опорный размер, реальный
        - вторая строка, первый столбей: целевой размер на изображении
        - вторая строка, второй столбец: целевой размер, реальный - ТОЛЬКО ДЛЯ ЧТЕНИЯ
        - из ячейки второй строки, второго столбца значение можно скопировать в буфер
    - кнопка копирующая целевой размер, реальный, вычесленный методом пропорций
