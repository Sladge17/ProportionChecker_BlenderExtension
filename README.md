# ProportionChecker

Blender расширение для вычисления реальных размеров по пропорциям.

## Требования

- Blender 5.0 или новее.

## Установка

Аддон распространяется в формате Blender **extension**, установка производится стандартным способом (Edit -> Preferences -> Get Extensions -> Install from Disk)

## Использование

Панель расположена в 3D Viewport → Sidebar → вкладка **ReferenceTools**.

- **Reference Images** — путь к папке с изображениями; количество найденных
  изображений показывается рядом. При изменении пути сетка перестраивается
  автоматически.
- **Images Grid**:
  - **Image Height** — высота плоскостей (метры);
  - **View Direction** — ось нормали плоскости (X/Y/Z);
  - **Distance between images:** **Horizontal** / **Vertical** — промежутки между
    плоскостями;
  - **View Offset** — смещение сетки вдоль оси нормали.
- **Dimensions** — таблица пропорций:
  - строка **Source** — реальный размер источника (`On image` и `Real`);
  - строка **Target** — размер цели на изображении и вычисленный целевой
    реальный размер;
  - кнопка **Clear** — очистить введённые значения;
  - кнопка **Copy to Buffer** — скопировать целевой реальный размер в буфер
    обмена.

Все плоскости размещаются в коллекции `ReferenceImages`. При перестройке старая
геометрия аддона удаляется.
